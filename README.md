# 동급생을 켜려다, 메모리를 배웠다

EMM386과 DOS의 기본 메모리·UMB·EMS·HMA를 설명하는 TECHTAEK 교육 자료.

- 공개 페이지: https://techtaek77.github.io/emm386-dos-memory-guide/
- index.html 하나에 이미지 5개와 교육용 메모리 계산 실험을 포함한다.
- 가상 계산은 실제 DOS·동급생 실행 시험이나 게임의 공식 요구 사양이 아니다.
- 개인 CPU·RAM·판본·실제 명령 옵션은 미확인으로 구분했다.
- 벨로키 삽화 3장은 AI 생성. 게임 이미지 2장은 참고 자료이며 출처는 페이지에 표시했다.
